# Machine Guardian multi-task MLP, training run 3: C_wd_slog (alternative with temperature)

Generated by `model/run3_hardware.py` / `model/run3_final_c.py` (3 Nov 2026) from the networks trained on all 7
development bearings (B02, B03, B04, B08, B09, B11, B12), seeds 0-4 (`seed<s>/`). Not frozen; not evaluated on the
locked test bearings; verified in RTL simulation only (Icarus, tb_mlp.sv), not on the ZedBoard.

Per seed: `W0-2.hex`, `Bias0-2.hex`, `Scl0-1.hex` (the files tb_mlp.sv reads), `mtl_run3.h` (C arrays for the ARM),
`quant.json` (every scale), `vectors_X.hex` / `vectors_C.hex` (64 test inputs and the expected raw sums).

Inputs, in this order: z_ln_lr_rms, z_ln_lr_peak, z_lr_kurt, z_ln_band_1k_5k, z_ln_band_5k_20k, z_lr_crest, rpm_z,
temp_resid_z, each a z-score against the motor's own first 100 operating measurements (model/mtl_inputs.py, A42).
Input transform (ARM): x = sign(z) * ln(1 + min(|z|, 10000)), then x_q = round(x / s_x) with s_x = ln(10001)/127.
x8 (temperature residual) IS used (MTL_USE_TEMPERATURE 1): 0 until the bearing's thermal model is calibrated.
Output column 0: deterioration logit; p = sigmoid((C[0] + bias_last[0]) * logit_scale_det); alarm after 3 consecutive
p > 0.5, then latched until a maintenance reset. Output column 1: the Motor Health Index head is UNTRAINED: never report it.
Dead weights (|w| < 1e-6 x the layer's largest) were set to 0 before quantization (FP32 output change: 0).
